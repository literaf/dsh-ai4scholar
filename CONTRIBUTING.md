# Contributions and licensing / 贡献与许可

The public project uses [AGPL-3.0-only](LICENSE). Separate commercial licensing is described in [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md) and covers only rights held by AI4Scholar.

Please identify the origin and license of any code or asset you contribute, preserve existing notices, and do not submit material you lack permission to contribute. Bug reports and discussion are welcome.

Before merging copyrightable external contributions, maintainers must confirm the rights needed for both the public AGPL edition and any intended commercial edition, arranging a separate contributor agreement when needed. Opening a pull request does not by itself transfer copyright or grant blanket commercial relicensing rights. This document is contribution guidance, not a signed contributor agreement.
